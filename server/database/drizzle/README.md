# Drizzle Migrations

This folder contains Drizzle ORM migrations for the CS2 Inspect database.

## Commands

Generate a new migration after schema changes:

```bash
bun run db:generate
```

Apply pending migrations:

```bash
bun run db:migrate
```

Push schema changes directly (development only):

```bash
bun run db:push
```

Open Drizzle Studio for database inspection:

```bash
bun run db:studio
```

Introspect existing database:

```bash
bun run db:introspect
```

## Migration Strategy

Since this project migrated from raw SQL to Drizzle ORM with an existing database:

1. The initial schema was created to match the existing database structure
2. New schema changes should be made in `server/database/schema/` files
3. Run `bun run db:generate` to create migration files
4. Migrations are automatically applied on server startup

## Notes

- The `meta/_journal.json` file tracks applied migrations
- Migration files are SQL files generated by drizzle-kit
- Never manually edit migration files after they've been applied
