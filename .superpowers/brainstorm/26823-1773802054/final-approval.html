State 2 — Sticker Selected Left panel slides away · Canvas expands · Sticker controls appended below weapon settings

Clicking a filled sticker slot activates edit mode. The left skin-picker panel slides out (animates to width 0, or collapses to a narrow "▶ Skins" toggle strip) giving the canvas more horizontal space. The canvas expands to fill the gap. The right panel keeps all weapon controls exactly as-is, then a labeled separator "Sticker #2" appears and below it: scale, rotation, X/Y position. A Done ✓ button at the bottom exits edit mode. The selected sticker slot in the strip pulses with a gold ring. An empty slot click still opens the sticker-picker modal.

State 3 — Keychain Selected Same expansion · Keychain-specific controls below weapon settings

Clicking the keychain slot behaves identically to sticker: left panel collapses, canvas expands. The canvas shows a purple circular drag handle — drag it anywhere on the gun to reposition the keychain. The right panel appends a "Keychain" separator below weapon controls — keychain only exposes an X/Y position (no scale, no rotation since keychains hang from a fixed anchor). A thin vertical "chain" line below the dot is drawn for visual feedback. Remove and Done ✓ at the bottom.
