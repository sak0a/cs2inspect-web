Sticker / Keychain Edit Mode
Clicking ✦ Edit in the canvas toolbar activates drag mode. The selected sticker gets resize handles and a dashed outline. The controls column swaps to show per-sticker controls (scale, rotation, position). Clicking another sticker selects it; clicking empty space deselects. Keychain gets a single drag anchor point. All other controls are greyed out until you exit edit mode.

Sticker / Keychain Edit Mode
Clicking ✦ Edit in the canvas bar activates placement mode. The canvas expands slightly (sticker strip hides temporarily) to give more drag space. The selected sticker shows resize handles directly on the canvas. The controls panel swaps to show scale, rotation, and X/Y position for that sticker. Clicking Done ✓ collapses back to normal. The Keychain is dragged via its purple anchor dot — no resize, just positioning.
